## HAF Block Explorer  ```  1.27.11  ```    ``` OAS 3.1 ```

[/hafbe-api/](https://api.syncad.com/hafbe-api/)

HAF block explorer is an API for getting information about transactions/operations included in Hive blocks, as well as block producer (witness) information.

[MIT License](https://opensource.org/license/mit)

[HAF Block Explorer gitlab repository](https://gitlab.syncad.com/hive/haf_block_explorer)

Servers

/hafbe-api

### [Block-search](https://api.syncad.com/\#/Block-search)    Information about blocks

GET
[/block-search](https://api.syncad.com/#/Block-search/hafbe_endpoints.get_block_by_op)

List block stats that match operation type filter, account name, and time/block range.

### [Transactions](https://api.syncad.com/\#/Transactions)    Information about transactions

GET
[/transaction-statistics](https://api.syncad.com/#/Transactions/hafbe_endpoints.get_transaction_statistics)

Aggregated transaction statistics

### [Accounts](https://api.syncad.com/\#/Accounts)    Information about accounts

GET
[/accounts/{account-name}](https://api.syncad.com/#/Accounts/hafbe_endpoints.get_account)

Get information about an account including Hive token balances.

GET
[/accounts/{account-name}/authority](https://api.syncad.com/#/Accounts/hafbe_endpoints.get_account_authority)

Get account's owner, active, posting, memo and witness signing authorities

GET
[/accounts/{account-name}/comment-permlinks](https://api.syncad.com/#/Accounts/hafbe_endpoints.get_comment_permlinks)

Get comment permlinks for an account.

GET
[/accounts/{account-name}/operations/comments/{permlink}](https://api.syncad.com/#/Accounts/hafbe_endpoints.get_comment_operations)

Get comment-related operations for an author-permlink.

### [Witnesses](https://api.syncad.com/\#/Witnesses)    Information about witnesses

GET
[/witnesses](https://api.syncad.com/#/Witnesses/hafbe_endpoints.get_witnesses)

List witnesses

GET
[/witnesses/{account-name}](https://api.syncad.com/#/Witnesses/hafbe_endpoints.get_witness)

Returns information about a witness.

GET
[/witnesses/{account-name}/voters](https://api.syncad.com/#/Witnesses/hafbe_endpoints.get_witness_voters)

Get information about the voters for a witness

GET
[/witnesses/{account-name}/voters/count](https://api.syncad.com/#/Witnesses/hafbe_endpoints.get_witness_voters_num)

Get the number of voters for a witness

GET
[/witnesses/{account-name}/votes/history](https://api.syncad.com/#/Witnesses/hafbe_endpoints.get_witness_votes_history)

Get the history of votes for this witness.

### [Other](https://api.syncad.com/\#/Other)    General API information

GET
[/version](https://api.syncad.com/#/Other/hafbe_endpoints.get_hafbe_version)

Get Haf\_block\_explorer's version

GET
[/last-synced-block](https://api.syncad.com/#/Other/hafbe_endpoints.get_hafbe_last_synced_block)

Get last block number synced by haf\_block\_explorer

GET
[/input-type/{input-value}](https://api.syncad.com/#/Other/hafbe_endpoints.get_input_type)

Determines object type of input-value.

GET
[/operation-type-counts](https://api.syncad.com/#/Other/hafbe_endpoints.get_latest_blocks)

Returns histogram of operation types in blocks.
